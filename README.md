**🛡️ Crime Lens AI**

*An AI-powered web application that simplifies crime news by generating clear and concise summaries.*

---

## Project Overview

Crime Lens AI is an intelligent web application designed to help users quickly understand crime-related news without reading lengthy articles. The application analyzes crime news content and generates a concise summary highlighting the most important information. It provides users with the key details of an incident in a simple and easy-to-read format, improving accessibility and saving time.

This project was developed as an AI-based solution by integrating a modern frontend with a Python backend and AI-powered text summarization.
